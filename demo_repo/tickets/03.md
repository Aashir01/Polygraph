# SHOP-03 — Tax computed before coupon deduction, over-charging coupon holders

**Type:** Bug  
**Priority:** High  
**Component:** `shop/tax.py`  
**Affects:** `compute_tax()`  
**Failing tests:**  
- `demo_repo/tests/test_tax.py::test_tax_with_coupon`  
- `demo_repo/tests/test_tax.py::test_tax_large_coupon_clamps_to_zero`

---

## Summary

`compute_tax()` applies the percentage discount before computing tax but omits the
flat coupon deduction.  Customers who redeem a coupon are taxed on an inflated
taxable amount — they pay more tax than they legally owe.

## Business Rule

Tax is levied on the **net amount the customer pays**:

```
taxable = subtotal × (1 − discount_rate) − coupon_amount   [clamped to 0]
tax     = taxable × tax_rate
```

Both the percentage discount **and** the coupon must be subtracted before tax is
applied.

## Steps to Reproduce

```python
from shop.tax import compute_tax

# subtotal=100, 10 % off → 90, minus $10 coupon → taxable=80
# expected tax = 80 × 0.08 = 6.40
result = compute_tax(100.00, discount_rate=0.10, coupon_amount=10.00)
print(result)   # → 7.20  (taxed on 90 instead of 80)
```

## Expected Behavior

```python
compute_tax(100.00, discount_rate=0.10, coupon_amount=10.00) == 6.40
compute_tax(50.00,  discount_rate=0.0,  coupon_amount=60.00) == 0.0   # clamped
```

## Actual Behavior

```python
compute_tax(100.00, discount_rate=0.10, coupon_amount=10.00) == 7.20  # over-charge
compute_tax(50.00,  discount_rate=0.0,  coupon_amount=60.00) == 4.00  # over-charge
```

## Root Cause

[`shop/tax.py`](../shop/tax.py) — `coupon_amount` is accepted as a parameter but
never subtracted from the taxable base:

```python
# current (buggy)
after_discount = subtotal * (1.0 - discount_rate)
# coupon deduction is missing here
taxable = max(0.0, after_discount)

# correct
after_discount = subtotal * (1.0 - discount_rate) - coupon_amount
taxable = max(0.0, after_discount)
```

## Fix

Add the coupon deduction in `compute_tax()` — single-line change in `shop/tax.py`.
